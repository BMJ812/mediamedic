Step 2 of 6

Bot Setup

Turn the application into a bot user and copy the bot token into MediaMedic.

Bot tab checklist

  1. Open the Bot section in the Developer Portal.
  2. Create the bot if Discord prompts you.
  3. Use Reset Token or Copy to get the bot token.
  4. Paste the token below. Keep it secret.
Discord Developer Portal → Bot → Token

Recommended bot settings

Use the defaults unless you know you need something else. MediaMedic does not need elevated intents for its current slash-command workflow.
After the bot exists, you can continue into OAuth2/installation from Discord. MediaMedic's bot token is the only Discord secret you store here.
Step 3 of 6

Permissions

Install the app to your server and make sure the bot can post its repair tracking cards in your issue channel.

What MediaMedic needs

Application command scope — install the app to your server so slash commands work.
Channel permissions in your issue channel:
  • View Channel
  • Send Messages
  • Embed Links
  • Read Message History
You do not need Administrator for MediaMedic. Keep permissions narrow.

Quick setup reminders

  1. Install the bot to the correct Discord server.
  2. Restrict the slash commands to your desired issue channel if you want tighter control.
  3. Also give the bot normal channel permissions in that same issue channel.

Server & Channel IDs

Paste the IDs that tell MediaMedic where it belongs and who can use it.
