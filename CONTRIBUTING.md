# Contributing to MediaMedic

Contributions are welcome.

## Ways to contribute

- Report bugs through GitHub Issues
- Suggest improvements or new repair workflows
- Improve the Web UI or Discord setup wizard
- Improve Radarr/Sonarr compatibility
- Improve Unraid packaging and documentation
- Submit pull requests with fixes or features

## Pull requests

1. Fork the repository.
2. Create a feature or fix branch.
3. Make focused changes.
4. Run the project's checks before submitting.
5. Open a pull request describing what changed, why it changed, and how it was tested.

## Security and secrets

Never commit or post:

- Discord bot tokens
- Radarr API keys
- Sonarr API keys
- Web UI passwords
- Private server configuration

Use placeholders in examples and redact secrets from logs.
